{% trans "1. Understanding your vet dashboard" %}

{% trans "Header bar (top of the page)" %}

  • {% blocktrans trimmed %}Date range & new cases graph: shows when new cases were received. Blue points = days with at least one new case.{% endblocktrans %}
  • {% blocktrans trimmed %}View all cases: opens the full list of cases assigned to you, grouped by status.{% endblocktrans %}
  • {% blocktrans trimmed %}Export: downloads all your cases as a CSV file that you can open in Excel.{% endblocktrans %}

{% trans "Key cards (top of dashboard)" %}

  • {% blocktrans trimmed %}Farmers Assigned: number of unique farmers you have served. Click “View farmers” to see recent farmers and their cases.{% endblocktrans %}
  • {% blocktrans trimmed %}Total Cases Solved: all cases you have resolved or closed.{% endblocktrans %}
  • {% blocktrans trimmed %}Total Cases Assigned: all cases that were ever assigned to you.{% endblocktrans %}
  • {% blocktrans trimmed %}Critical Cases: active cases with critical severity that need urgent attention.{% endblocktrans %}

{% trans "Case Statistics (big graph)" %}

  • {% blocktrans trimmed %}Shows new cases per day for the last 12 months.{% endblocktrans %}
  • {% blocktrans trimmed %}Hover a point to see the exact date and the number of new cases you received that day.{% endblocktrans %}

{% trans "Resolution Rate card" %}

  • {% blocktrans trimmed %}Big % = overall resolution rate for all your cases.{% endblocktrans %}
  • {% blocktrans trimmed %}Green text below shows how many cases you have resolved this month.{% endblocktrans %}
  • {% blocktrans trimmed %}The green mini-graph shows your monthly resolution rate over the last 12 months.{% endblocktrans %}

{% trans "Assigned cases table (bottom)" %}

  • {% blocktrans trimmed %}Each row is a case with date, farmer name, predicted disease, severity and status.{% endblocktrans %}
  • {% blocktrans trimmed %}Click “View” to open the case detail page, enter your diagnosis and recommendations, and then mark the case as resolved when appropriate.{% endblocktrans %}
{% trans "2. Working with cases step by step" %}
  1. {% blocktrans trimmed %}Open your case list: Use the sidebar “Cases” link to see all assigned, in‑progress, and resolved cases.{% endblocktrans %}
  2. {% blocktrans trimmed %}Review farmer information: From the dashboard or the “Farmers” menu, you can see which farmers are under your care and their recent cases.{% endblocktrans %}
  3. {% blocktrans trimmed %}Open a case detail: Click “View” on any case to see: symptoms, predicted disease, severity, farm location and farmer contact information.{% endblocktrans %}
  4. {% blocktrans trimmed %}Record your diagnosis and recommendations: Use the form on the case detail page to enter your professional diagnosis and clear treatment recommendations (dosage, quarantine, follow‑up, etc.).{% endblocktrans %}
  5. {% blocktrans trimmed %}Update status: When you finish, mark the case as “Resolved” / “Closed” so that the farmer and Ministry can see that the case has been attended.{% endblocktrans %}
{% trans "3. Communicating with Ministry" %}

{% trans "Requesting vaccines / medical stock" %}

  • {% blocktrans trimmed %}In the sidebar, click “Request vaccines”.{% endblocktrans %}
  • {% blocktrans trimmed %}Fill in the title, product name, estimated quantity, priority (Normal or Urgent), and a clear justification (disease, area, herd size).{% endblocktrans %}
  • {% blocktrans trimmed %}After you submit, you can see the status and Ministry response in the same page.{% endblocktrans %}

{% trans "Writing area reports" %}

  • {% blocktrans trimmed %}Use the “Area reports” link in the sidebar.{% endblocktrans %}
  • {% blocktrans trimmed %}Send monthly or outbreak reports describing disease trends, challenges and your recommendations for the area.{% endblocktrans %}
  • {% blocktrans trimmed %}Ministry can respond to these reports; you will see their feedback in the same list.{% endblocktrans %}

{% trans "What information is most helpful?" %}

  • {% blocktrans trimmed %}Clear description of clinical signs you are observing.{% endblocktrans %}
  • {% blocktrans trimmed %}Approximate number of affected animals and herds.{% endblocktrans %}
  • {% blocktrans trimmed %}Any suspected disease based on your experience.{% endblocktrans %}
  • {% blocktrans trimmed %}Urgency: is this a local outbreak or a wider regional trend?{% endblocktrans %}
{% trans "4. Tips for using CattleCare AI effectively" %}
  • {% blocktrans trimmed %}Confirm AI predictions with your clinical judgement – the system is a support tool, not a replacement for your expertise.{% endblocktrans %}
  • {% blocktrans trimmed %}Keep statuses up to date (Assigned → In progress → Resolved) so that Ministry and farmers can see real‑time progress.{% endblocktrans %}
  • {% blocktrans trimmed %}Use clear language in recommendations so farmers can follow treatment safely.{% endblocktrans %}
  • {% blocktrans trimmed %}Export your cases regularly if you need to keep personal records for audits, CPD or reporting.{% endblocktrans %}
