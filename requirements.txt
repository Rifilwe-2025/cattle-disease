# Runtime - everything needed to serve the site and run predictions.
#
# Versions are pinned, not ">=". Two reasons learned the hard way:
#   - scikit-learn MUST stay at 1.8.0. The .pkl artifacts in the project root
#     were built with 1.8.0; a newer version unpickles them with an
#     InconsistentVersionWarning and may give invalid predictions. If you
#     retrain the model, bump this pin to whatever version you trained with.
#   - The old loose constraints made pip backtrack for ~40 minutes on a slow
#     connection before installing anything.
#
# Install:  venv\Scripts\python.exe -m pip install -r requirements.txt
